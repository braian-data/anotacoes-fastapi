# anotacoes-fastapi

Projeto de aprendizado onde implemento do zero até o deploy, passo a passo.

- [ ] CRUD completo de anotações
- [ ] Banco de dados SQLite
- [ ] Testes básicos com Pytest

### 2. Evolução
- [ ] Migração para PostgreSQL
- [ ] SQLAlchemy + Alembic (migrations)
- [ ] Docker

### 3. Finalização
- [ ] Deploy no Render
- [ ] Documentação com Swagger
- [ ] Autenticação de usuários
- [ ] Atualização completa do README
